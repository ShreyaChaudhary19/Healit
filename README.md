# 💙 Healit — AI-Powered Healthcare Assistant

**Healit** is a healthcare mobile application designed to make health information, personal health tracking, and healthcare support more accessible through a simple, user-friendly interface.

The project focuses on providing users with a convenient place to explore health-related features, manage personal health information, and access healthcare assistance.

## ✨ Features

- 🏥 **Health Dashboard** — A central interface for accessing healthcare features.
- 🤖 **AI Health Assistant** — An interface for AI-based health assistance.
- 📊 **Health Analytics** — Health insights, visualizations, and progress tracking.
- 🩺 **Doctor Directory** — Browse doctor information and access appointment-related features.
- 🚨 **Emergency Assistance** — Emergency services, emergency contacts, and medical information.
- 💊 **Medicine Management** — A dedicated screen for medicine-related information.
- 📁 **Medical Records** — An interface for organizing and accessing health records.
- 👤 **User Profiles** — Account and profile management.
- 🔐 **Authentication** — Login, registration, and password recovery screens.

*Feature availability depends on the current implementation of the application.*

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- Git
- Expo Go on a compatible mobile device, or an Android emulator

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ShreyaChaudhary19/Healit.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Healit
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the Expo development server:

   ```bash
   npx expo start
   ```

5. Follow the Expo CLI instructions to run the application on a compatible device or emulator.
